# 🚀 无水印视频解析系统 - 启动指南

## 📋 系统架构

```
无水印视频解析系统
├── 前端 (React) - 端口 3000
│   ├── 用户界面
│   ├── 视频链接解析
│   └── 结果展示
└── 后端 (Node.js) - 端口 3001
    ├── apia.vip API集成
    ├── 错误处理
    └── 演示数据回退
```

## 🔧 环境要求

- **Node.js**: 版本 14+ 
- **npm**: 版本 6+
- **浏览器**: Chrome, Firefox, Safari, Edge (现代浏览器)

## 🚀 快速启动

### 方法1: 一键启动 (推荐)
```bash
# 1. 安装所有依赖 (前端 + 后端)
npm run full:install

# 2. 同时启动前后端服务
npm run full:dev
```

### 方法2: 分别启动
```bash
# 1. 启动后端服务 (端口 3001)
npm run server:dev

# 2. 新开终端启动前端 (端口 3000)
npm run dev
```

### 方法3: Windows 用户
```bash
# 双击 server/start.bat 启动后端
# 然后在项目根目录运行
npm run dev
```

## 🛠️ 故障排除

### 后端服务启动失败
```bash
# 检查端口占用
netstat -ano | findstr :3001  # Windows
lsof -i :3001                 # Mac/Linux

# 重新安装依赖
cd server
npm install
```

### 前端无法连接后端
```bash
# 检查网络连接
curl http://localhost:3001/api/health

# 检查CORS设置
# 后端已配置CORS，一般不会有跨域问题
```

### API解析失败
```bash
# 检查apia.vip服务状态
curl "https://apia.vip/api/dsp/329D8FDBADD4453C2AF7A9C3059549F9A932D1B766504AB8F7/202037297/?url=https://v.douyin.com/test"

# 查看后端日志
# 在server目录查看控制台输出
```

## 🔒 安全说明

- **API密钥**: 已预配置在后端，无需额外设置
- **跨域**: 后端已配置CORS，支持本地开发
- **错误处理**: 内置完善的错误处理和演示数据回退

## 📞 技术支持

如果遇到问题，请检查：

1. **Node.js版本**: `node --version`
2. **npm版本**: `npm --version`  
3. **端口占用**: 确保3000和3001端口未被占用
4. **网络连接**: 确保可以访问apia.vip
5. **控制台日志**: 查看详细错误信息
