- parseInt()
  - parseInt(x/10) 返回整数,舍弃小数部分
    - % 是取模运算符，返回除法的余数

  - 将字符串转化为整数
    - parseInt(string,radix)
    - string 被解析的字符串值
    - radix  这是指定的基数,例如10,表示十进制
    - parseInt("123.45", 10) 返回 123
  
- Math.sort((a, b) => a - b) 从小到大排序

- Math.abs() JavaScript 内置 Math 对象的一个静态方法，它的作用是返回一个数的绝对值。
